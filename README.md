# OpenCode plugins

## Plugins

- [`opencode-figma`](figma/README.md): Figma files and annotations in a session's side panel.
- [`opencode-pull-requests`](github/README.md): GitHub pull request panel, composer pill, and pull request browser.
- [`opencode-activity-indicator`](activity-indicator/README.md): macOS menu bar session status and Dock badges for pending input prompts.
