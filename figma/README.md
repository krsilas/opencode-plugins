# opencode-figma

OpenCode plugin: Figma files in a session's side panel, with areas you annotate attached to the prompt.

## Develop

```sh
pnpm install       # run once in the workspace root
pnpm dev           # run these package scripts from figma/
pnpm lint          # Vite+ lint; lint:fix applies safe fixes
pnpm format        # format source and tests; format:check verifies
pnpm typecheck
pnpm test
```
